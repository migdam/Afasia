## Getting Started

### System Requirements

**Minimum Requirements:**
- Modern web browser (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+)
- Internet connection (for initial setup)
- Microphone (for pronunciation exercises)
- Speakers or headphones (recommended)

**Recommended:**
- Desktop or laptop computer for best experience
- Tablet or smartphone (mobile-responsive)
- Stable internet connection
- Quiet environment for pronunciation practice

### Accessing the Application

1. Open your web browser
2. Navigate to the application URL
3. You'll see the login/registration page

## Creating Your Account

### Registration Process

1. **Click "Register"** on the login page

2. **Fill in your details:**
   - **Email**: Valid email address (for account recovery)
   - **Username**: Choose a unique username (3-50 characters)
   - **Full Name**: Your real name (optional but recommended)
   - **Password**: Strong password (min 8 characters)

3. **Select Language:**
   - English (EN)
   - Polish (PL)

4. **Click "Register"**

5. **You'll be automatically logged in** and taken to your dashboard

### Security Tips

✅ **Choose a strong password:**
- At least 8 characters
- Mix of uppercase and lowercase letters
- Include numbers and special characters
- Don't use common words

✅ **Keep your credentials safe:**
- Don't share your password
- Use a password manager
- Log out on shared computers

## Starting a Therapy Session

### Step-by-Step Guide

#### Step 1: Choose Exercise Type

Four types available:

1. **Word Naming** 🖼️
   - Look at images
   - Name what you see
   - Good for vocabulary building

2. **Sentence Completion** ✏️
   - Read incomplete sentences
   - Choose the right word
   - Improves grammar skills

3. **Image Recognition** 🎨 (not available yet)
   - Match images to words
   - Visual learning
   - Memory enhancement

4. **Pronunciation** 🎤
   - Listen to words
   - Record your pronunciation
   - Speech practice

#### Step 2: Select Difficulty

- **Easy** 🟢
  - Simple, common words
  - Basic sentences
  - Fewer options
  - Best for beginners

- **Medium** 🟡
  - Moderate vocabulary
  - Complex sentences
  - More challenging
  - Most popular choice

- **Hard** 🔴
  - Advanced words
  - Difficult sentences
  - Expert level
  - For experienced users

#### Step 3: Set Number of Exercises

- Minimum: 5 exercises
- Maximum: 50 exercises
- Recommended: 10-15 for beginners

#### Step 4: Click "Start"

The session will begin immediately!

### During a Session

**Exercise Screen Layout:**

```
[Exit] ────────── [Progress: 3/10] ────────── [Timer: 02:15]
                   ▓▓▓▓░░░░░░ 30%

┌─────────────────────────────────────────────────────────┐
│                                                         │
│                    [Image if applicable]                │
│                                                         │
│         What is this? (Choose the correct answer)      │
│                                                         │
│   ┌──────────┐  ┌──────────┐  ┌──────────┐           │
│   │   Cat    │  │   Dog    │  │   Bird   │           │
│   └──────────┘  └──────────┘  └──────────┘           │
│                                                         │
│              [Submit Answer Button]                     │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**Progress Indicators:**
- **Counter**: Shows current exercise (e.g., "3/10")
- **Progress Bar**: Visual progress indicator
- **Timer**: Time spent on current session

**Controls:**
- **Exit**: Leave session (progress will be lost)
- **Submit**: Check your answer
- **Play Audio**: (Pronunciation exercises) Hear the word (not available yet: there are no recordings)

### Feedback

After submitting an answer:

✅ **Correct Answer:**
- Green feedback box
- "Correct! Well done!"
- Automatic progression to next exercise

❌ **Incorrect Answer:**
- Red feedback box
- "Not quite. Correct answer: …", with the right answer in bold
- Automatic progression after 2 seconds

### Completing a Session

When you finish all exercises:
1. Session summary appears
2. Your score is displayed
3. Points are awarded
4. Badges may be unlocked
5. Return to dashboard

## Exercise Types

### 1. Word Naming Exercises

**How it works:**
1. A short description of an everyday thing appears (pictures will be added later)
2. The question is: "What is it?"
3. You type the word or select from options
4. Submit your answer

**Tips for Success:**
- Look carefully at the image
- Take your time
- Think about what you see first
- Don't guess randomly

**Scoring:**
- Exact match required
- Spelling counts
- Case-insensitive

### 2. Sentence Completion

**How it works:**
1. Read a sentence with a blank: "The sky is ___"
2. Choose from 4 multiple-choice options
3. Select the word that fits best
4. Submit your answer

**Tips for Success:**
- Read the entire sentence
- Eliminate obviously wrong answers
- Consider grammar (noun, verb, etc.)
- Think about meaning

**Scoring:**
- Only one correct answer
- No partial credit

### 3. Image Recognition

**Not available yet:** there are no image-recognition exercises, so starting this type shows an error message.

**How it works:**
1. See an image
2. Get multiple word options
3. Match the image to the correct word
4. Submit your choice

**Tips for Success:**
- Focus on details in the image
- Consider context
- Use elimination method
- Trust your first instinct

### 4. Pronunciation Practice

**How it works:**
1. See a word or phrase
2. Click "Play Audio" to hear it (not available yet: there are no recordings)
3. Click "Record" to practice
4. Speak clearly into microphone
5. Click "Stop" when done
6. Submit your recording

**Tips for Success:**
- Listen to the example multiple times
- Practice in a quiet place
- Speak clearly and slowly
- Position microphone close to mouth
- Don't rush

**Technology Used:**
- Web Audio API for playback
- MediaRecorder API for recording
- Web Speech API for evaluation (if available)

## Using Voice Recording

### Setup

#### 1. **Grant Microphone Permission**

First time using pronunciation exercises:
1. Browser will ask for microphone access
2. Click "Allow"
3. Permission is saved for future use

If you accidentally denied permission:
1. Click the lock icon in address bar
2. Find microphone settings
3. Change to "Allow"
4. Refresh the page

#### 2. **Test Your Microphone**

Before starting:
1. Click "Record" button
2. Say "Testing 1, 2, 3"
3. Click "Stop"
4. Listen to playback
5. Adjust volume if needed

### Recording Process

**Step-by-Step:**

1. **Listen to Example**
   - Click "Play Audio" button (not available yet: there are no recordings)
   - Hear the correct pronunciation
   - Listen multiple times if needed

2. **Prepare to Record**
   - Click "Record" button
   - Button turns red and pulses
   - Microphone is now active

3. **Speak Clearly**
   - Say the word or phrase
   - Speak at normal pace
   - Pronounce clearly

4. **Stop Recording**
   - Click "Stop" button
   - Recording is saved automatically

5. **Submit**
   - Click "Submit" when ready
   - Recording is uploaded
   - Evaluation begins (if available)

### Tips for Best Results

✅ **Environment:**
- Quiet room
- Minimal background noise
- Close windows
- Turn off TV/radio

✅ **Microphone Position:**
- 6-12 inches from mouth
- Slightly off to the side
- Avoid breathing directly into mic

✅ **Speaking Technique:**
- Natural volume (not too loud/soft)
- Clear enunciation
- Normal pace
- Relax your jaw

✅ **Technical:**
- Use headphones to avoid feedback
- Check microphone is working
- Close other apps using microphone
- Ensure good internet connection

### Troubleshooting Recording

**Problem: Can't hear playback**
- Check device volume
- Check browser volume
- Try different browser
- Restart device

**Problem: Recording not working**
- Check microphone permission
- Try different browser
- Check microphone is connected
- Test microphone in other apps

**Problem: Poor quality**
- Move closer to microphone
- Reduce background noise
- Check microphone quality
- Use external microphone

## Scheduling Sessions

### Why Schedule?

Benefits of planning ahead:
- Build consistent routine
- Get reminder notifications
- Never forget practice time
- See your commitment visually

### How to Schedule

**Method 1: From Dashboard**

1. Click "Add Schedule" button
2. Fill in the form:
   - **Title**: Name your session (e.g., "Morning Practice")
   - **Date & Time**: Pick when you want to practice
   - **Exercise Type**: Choose exercise type
   - **Difficulty**: Select difficulty level
3. Click "Schedule"
4. Session appears in "Scheduled Sessions" list

**Method 2: Quick Schedule**

After completing a session:
1. Click "Schedule Next Session"
2. Pre-filled with same settings
3. Adjust time as needed
4. Confirm

### Managing Scheduled Sessions

**View Upcoming:**
- See all scheduled sessions on dashboard
- Sorted by date (soonest first)
- Shows type, difficulty, date/time

**Delete Schedule:**
- Click trash icon next to session
- Confirm deletion
- Session is removed

**Edit Schedule:**
- Delete old schedule
- Create new one with updated details
- (Direct editing coming in v1.1)

### Best Practices

⏰ **Timing:**
- Schedule same time daily
- Choose when you're most alert
- Allow 15-30 minutes
- Avoid meal times

📅 **Frequency:**
- Start with 3-4 times per week
- Gradually increase
- Rest days are important
- Consistency > intensity

🎯 **Variety:**
- Mix exercise types
- Vary difficulty levels
- Keep sessions interesting
- Challenge yourself gradually

- Share progress with therapist

## FAQ

### General Questions

**Q: Is this free to use?**
A: [Specify your pricing model]

**Q: Do I need to download anything?**
A: No, it's a web application. Just use your browser. You can optionally install it as a PWA (Progressive Web App) to your home screen.

**Q: Can I use it on mobile?**
A: Yes! The app is fully responsive and works on phones and tablets.

**Q: Is my data private?**
A: Yes, your data is stored securely. See our Privacy Policy for details.

**Q: Can I delete my account?**
A: Yes, contact support to request account deletion.

### Sessions & Exercises

**Q: How long does a session take?**
A: Depends on number of exercises. Typically:
- 5 exercises: 3-5 minutes
- 10 exercises: 7-10 minutes
- 20 exercises: 15-20 minutes

**Q: Can I pause a session?**
A: No, sessions must be completed in one sitting. Choose an appropriate number of exercises.

**Q: What happens if I close the browser during a session?**
A: Progress is lost. You'll need to start a new session.

**Q: Can I repeat exercises?**
A: Yes, start a new session anytime. Exercises are randomized.

**Q: Are exercises the same each time?**
A: Exercises are randomly selected from a pool, so you'll see variety but may encounter repeats.

### Progress & Scoring

**Q: How are points calculated?**
A: Points depend on:
- Difficulty level (Easy: 10, Medium: 20, Hard: 30)
- Correctness (correct answer only)
- No points for incorrect answers

**Q: What breaks a streak?**
A: Missing a day. Streaks require consecutive daily practice.

**Q: Can I see other users' scores?**
A: No, your progress is private. Only you and authorized therapists can see your data.

**Q: How is accuracy calculated?**
A: (Correct answers / Total answers) × 100%

### Technical Questions

**Q: What microphone should I use?**
A: Any microphone works. Built-in laptop/phone mics are fine. External USB mics provide better quality.

**Q: Why does the app ask for microphone permission?**
A: Required for pronunciation exercises. You can deny if only using other exercise types.

**Q: Can I use it offline?**
A: Partially. With the PWA installed, some features work offline, but syncing requires internet.

**Q: Which browsers work best?**
A: Chrome and Edge provide the best experience, especially for speech recognition features.

**Q: Is there a mobile app?**
A: Not yet, but the web app works great on mobile. Install as PWA for app-like experience.

### Account & Security

**Q: I forgot my password. What do I do?**
A: [Describe password reset process if available, or contact support]

**Q: Can I change my username?**
A: No, usernames are permanent. Choose carefully during registration.

**Q: Can I have multiple accounts?**
A: Each email address can only have one account.

**Q: How do I log out?**
A: Click the "Logout" button in the top navigation bar.

### Features

**Q: Can I customize exercises?**
A: Not yet. Custom exercises are planned for version 1.2.

**Q: Can my therapist see my progress?**
A: If they have an admin account and you're assigned to them, yes.

**Q: Are there video exercises?**
